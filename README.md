# miocase8989

Aplicación móvil y web de marketplace comunitario para Yacuiba, construida con Expo, React Native y Supabase.

## Inicio rápido

1. Instala Node.js y npm.
2. Ejecuta `npm install`.
3. Copia `.env.example` a `.env` y completa `EXPO_PUBLIC_SUPABASE_URL` y `EXPO_PUBLIC_SUPABASE_ANON_KEY`.
4. Aplica en orden las migraciones de `supabase/migrations/` en tu proyecto Supabase.
5. Ejecuta `npm start` y elige Android, iOS o web.

No subas `.env` ni claves privadas al repositorio. La configuración de Supabase y los pasos de ejecución están descritos en [PROJECT_GUIDE.md](./PROJECT_GUIDE.md).
